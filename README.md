# PINGUI

PINGUI is a playful English-learning web app built with React and Vite. It includes skill practice, a level-based learning path, progress tracking, achievements, a searchable vocabulary collection, saved and learned words, and flashcards.

The published site is available at [kirillitti228.github.io/pingui](https://kirillitti228.github.io/pingui/). Updates to `main` are built and deployed with GitHub Actions.

## Run locally

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

## Progress and settings

Learning progress, vocabulary collections, interface language, and preferences are stored in this browser using localStorage. English is the learning language; the interface supports English, Norwegian, Russian, and Ukrainian.
